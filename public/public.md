# Public Assets

This directory contains static public assets, branding logos, icons, and web crawler instructions served by Vite / Firebase Hosting.

## Files

| File | Description |
|---|---|
| `favicon.ico` | Web browser tab icon file for OS3 web application. |
| `os3-logo.png` | High-resolution PNG logo image asset. |
| `os3-logo.svg` | Scalable vector graphic (SVG) logo asset. |
| `placeholder.svg` | Placeholder SVG graphic used in UI image loading fallbacks. |
| `robots.txt` | Search engine indexing rules document for search crawlers. |
