# Backend Data

This directory contains static datasets and knowledge base JSON files used by the
RAG pipeline to embed security context and answer user queries in the AI Copilot.

## Files

| File | Description |
|---|---|
| `os3_context.json` | Project overview, problem statement, features, and usage context used for RAG vector embeddings. |
| `vulnerabilities.json` | Sample dataset of package vulnerabilities, CVE identifiers, risk severities, and remediation fixes. |
