# OS3 CLI Embedded Services

This directory contains embedded security services and API clients packaged inside the CLI.

## Files

| File | Description |
|---|---|
| `attack_path_detector.py` | Embedded attack path detection algorithm implementation. |
| `dependency_analyzer.py` | Embedded recursive dependency tree resolution service. |
| `dependency_graph.py` | Embedded graph data structure builder utility. |
| `dependency_service.py` | Embedded dependency resolution wrapper interface. |
| `npm_service.py` | Embedded npm registry API client for package metadata. |
| `osv_service.py` | Embedded OSV vulnerability database query client. |
