# Frontend Components

This directory contains layout elements, header navigation, visual metric cards, graph display controls, and Shadcn UI primitives.

## Files

| File | Description |
|---|---|
| `DependencyGraph.tsx` | Visual component rendering dependency graph nodes and connection lines using SVG. |
| `Navigation.tsx` | Main application top navbar component containing logo, route links, and theme elements. |
| `NavLink.tsx` | Navigation link helper component managing active path styling. |
| `PageTransition.tsx` | Motion transition component wrapping route elements with smooth entry/exit animations. |
| `ScoreBar.tsx` | Animated security score progress bar component with color-coded severity indicator. |
| `Scoreboard.tsx` | Overview dashboard card displaying security scores, total vulnerabilities, and risk labels. |
