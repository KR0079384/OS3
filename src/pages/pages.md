# Frontend Pages

This directory contains the main page views and route components of the OS3 web application.

## Files

| File | Description |
|---|---|
| `AICopilot.tsx` | AI Security Copilot interactive page supporting live security QA and streaming CVE answers. |
| `Compare.tsx` | Side-by-side package comparison page comparing security scores, metrics, and risks across dependencies. |
| `Dashboard.tsx` | Main security overview page displaying security score, risk distributions, and metric cards. |
| `DependencyGraph.tsx` | Interactive ReactFlow graph page visualizing package dependency trees and attack paths. |
| `Explore.tsx` | Package search and registry explorer page for discovering open-source packages. |
| `Intelligence.tsx` | Supply chain security threat intelligence dashboard showcasing global vulnerability trends. |
| `Landing.tsx` | Marketing landing page featuring hero banner, problem statement, features, and CLI installation CTA. |
| `NotFound.tsx` | 404 fallback page displayed when accessing non-existent application routes. |
| `Recommendations.tsx` | Safe package alternatives and vulnerability upgrade recommendation page. |
| `Scan.tsx` | Real-time package scanner page for entering package names and generating pre-install risk reports. |
| `Vulnerabilities.tsx` | Vulnerabilities view listing CVE details, severities, CVSS scores, and remediation recommendations. |
